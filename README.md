# 🎮 Arcadia — Gaming Café Management System

**Arcadia** is a modern, interactive Gaming Café Management System designed to enhance the gaming café experience through a neon-themed interface, gaming features, and efficient database management.

Built with a dark aesthetic, neon lighting effects, and gaming-inspired typography, Arcadia combines an engaging user experience with practical café management functionality.

### ✨ Key Features
- 🎮 **Four Interactive Games:** Explore and enjoy four games integrated into the website.
- 🖥️ **Gaming Session Management:** Manage gaming sessions, track session details, and monitor session status.
- 👥 **Customer Management:** Maintain customer records and membership information.
- 💳 **Dynamic Membership Discounts:** Apply membership-based discounts to gaming sessions.
- 🗄️ **MySQL Database:** Store and manage customers, gaming PCs, memberships, and session records.
- ⚙️ **Stored Procedures:** Implement database operations and business logic using MySQL stored procedures.
- 🔄 **Database Automation:** Use triggers to automate relevant database operations and maintain data consistency.
- 🖱️ **Cursor-Based Operations:** Use database cursors where appropriate to process records.
- 🌌 **Neon Gaming UI:** Enjoy a dark-themed interface with neon accents and a futuristic gaming atmosphere.

### 🛠️ Technology Stack
- **Frontend:** HTML, CSS, JavaScript, React, TypeScript
- **Build Tool:** Vite
- **Database:** MySQL
- **Database Concepts:** Stored Procedures, Triggers, Cursors, Transactions, and Relational Database Design
- **Version Control:** Git and GitHub

### 🎯 Project Objective
The objective of Arcadia is to demonstrate how web development and database management concepts can be combined to create an interactive gaming café platform. The project focuses on customer management, gaming session tracking, membership discounts, and database-driven business logic.
